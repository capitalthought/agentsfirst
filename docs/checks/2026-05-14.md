1. (+2) Server returns `MISSING_REQUIRED_CLIENT_CAPABILITY` instead of crashing when client lacks a needed capability.
2. (+2) Server validates `io.modelcontextprotocol/protocolVersion` and returns `UnsupportedProtocolVersionError` (HTTP 400) on mismatch.
3. (-2) Server reads capabilities from initialization state instead of per-request `_meta`.

**Effort:** ~half-day when the spec ships; trivial today (just track).
