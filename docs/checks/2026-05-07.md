- Add a rubric line: +3pts for a stateless `tools/list` (cacheable per-deployment); -2pts if the server requires `Mcp-Session-Id`.
- Bump rubric version (likely v0.1.4 → v0.1.5).
- Run an automatic rescore against any /reports/ MCP-server pages that touched session state.

- Token count >3000
