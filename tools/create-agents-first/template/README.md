An Agents-First MCP server scaffold. Generated by [`@capitalthought/create-agents-first`](https://www.npmjs.com/package/@capitalthought/create-agents-first).

Built around the 8 implementation principles from <https://agentsfirst.dev>: Interface First, Contract First, Prep Gates, Typed State, Visible Outputs, Multi-Model Verification, Perspective Dispatch, Autonomous Recovery.

## Quick start

```bash
npm install
npm run prep         # verify the prep gate passes
npm run dev          # run the MCP server (stdio transport)
```

Then point your MCP-aware agent at it:

- **Claude Code:** add to `~/.claude/claude_desktop_config.json` (or per-project) — `"command": "tsx", "args": ["src/server.ts"]` from this directory.
- **Cursor / Windsurf / Zed:** point to `tsx src/server.ts` (dev) or `node dist/server.js` (after `npm run build`).

The agent will see three tools immediately: `{{PROJECT_NAME}}_prep`, `example_create`, `example_list`.

## Next steps

In rough order:

1. **Edit `AGENTS.md`** — replace the placeholder rules with your real domain rules. The agent obeys whatever's in this file; vague rules produce vague behaviour.
2. **Wire `src/prep.ts`** — replace the placeholder `REQUIRED_ENV` array and `data/` check with your real auth + state validations.
3. **Replace `example_create` and `example_list`** — these are stubs. Build your real domain tools using the same shape: verb-first names, Zod-typed params, structured error returns.
4. **Wire Visible Outputs** — find the `// TODO: ship to Slack/email/task manager` comments in `src/server.ts` and post to wherever your humans actually look.
5. **Add Multi-Model Verification** for high-stakes writes — billing, deploys, security-sensitive operations. Cheap insurance.
6. **Persist your state** — `src/state.ts` is in-memory. Swap in Postgres / SQLite / KV when you outgrow that.

## Levels of adoption

| Level | Marker |
|---|---|
| 0 | No agent access |
| 1 | Lazy wrapper (you're past this) |
| **2** | **You start here.** AGENTS.md exists. State is typed. Prep gate validates. |
| 3 | Agents-First — agent interface designed and shipped first, agent is primary consumer |
| 4 | Agent-Driven — self-healing, multi-model checks, agents extend the system |

Goal for net-new projects: ship at Level 2 today, climb to Level 3 within a sprint.
